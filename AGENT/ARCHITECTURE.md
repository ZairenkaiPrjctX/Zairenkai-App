# Architecture: Zairenkai-App

> Owned by this repository. Document only what inspected code supports, citing file paths.

## Status

Implemented and tested on the JVM; not yet run on a device. Full description:
`docs/architecture/overview.md`.

## Entry points

- `MainActivity` (launcher).
- `ZairenkaiApplication`, which owns the `AppContainer`.

## Data flow

- Probes run on IO and publish a `StateFlow<RegistrySnapshot>`.
- View models call the clients on IO and expose `StateFlow`s.
- Compose collects them with lifecycle awareness.

## External interfaces

- `zcored ctl` and `zfasd ctl` through `su` (`docs/architecture/integration-map.md`).
- The packaged `libzart.so` and `libzthermal.so` (only `zthermal snapshot`).
- Packaged assets.
- No network.

## Trust boundaries

- **App uid:** public APIs, `zart inspect` and `zthermal snapshot`.
- **Root:** only after consent, and only fixed commands.
- **No secrets:** none in the repository or the APK.

## Generated artifacts

- `integration/out/` (`build-components.sh`; git-ignored) supplies the jniLibs and assets.
- `integration-core/src/test/resources/contracts/` is regenerated by `capture-contracts.sh`.
  Do not hand-edit.
