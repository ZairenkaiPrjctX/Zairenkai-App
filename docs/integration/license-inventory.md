# Licence inventory

What the APK contains, and under which terms. Revisions come from
`integration/repository-lock.json`, the font from `integration/third-party-assets.json`.
Checked 2026-10-21 against the checkouts at the pinned commits.

**Distribution status: blocked.** The App, ART (zart) and FAS have no licence. The release
gate (`verify_integration.py report --release`) fails on each of them, so only engineering
builds exist (`docs/build/release.md`).

Each crate's licence and notice texts are reproduced in full. The script fails if a crate
declares no licence or ships no licence text.

Every notice file is viewable in System › Licences. `verify_integration.py build` and `apk`
fail if one is missing.

## Not packaged

- Core and FAS source: only their module zips, built by their own scripts.
- AFID code (Apache-2.0), ART upstream patches, release scripts, CI configuration and signing
  material.

## Open items

1. **Choose licences.** Zairenkai-App, Zairenkai-ART and Zairenkai-FAS need one. Their source
   permits any choice the owner makes: no copied GPL code, permissive dependencies only. The
   decision is the maintainer's, not an agent's.
2. **Crate notices in the zip.** Core's (and later FAS's) `build-android.sh` should put the crate
   notices into the module zip itself, so the zip carries them when copied out of the APK.
